# Dependency bridge

Read the generated card first: `docs/pitfalls/dep-bridge.md`. It lists every lint rule and every build-cited native
failure for this area. The card is generated by `tools/validate/pitfall_cards.py`; never edit it by hand, and
regenerate it after changing a rule message or a build-cited comment.

- Expansion AI, COT and CF calls go only through the HC bridge classes (lint HC-E022 and HC-E027). No direct
  `eAI*` or COT calls elsewhere.
- The bridge validates invariants and refuses with a reason code; callers log or relay the reason.
- A raw `eAIGroup` handle is not auto-nulled when the group is freed. Keep it through `HCXAIGroupHold`
  (`HCXAIGroupHolds.Follow/Retire`) or store a group id and resolve it before every use.
- Inspect the installed dependency scripts before calling an API; do not build on unobserved engine APIs.
- No teleports for players, no omniscient AI, no unlimited alerts.
- A dependency-boundary brief carries a design review line.
